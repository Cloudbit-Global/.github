# Code of Conduct

`Cloudbit-Global` adopts the [Contributor Covenant Code of Conduct (v2.1)](https://www.contributor-covenant.org/version/2/1/code_of_conduct/).

## Expected Behavior
* Maintain respectful, constructive, and technically focused communication across issues, pull requests, and community channels.
* Focus feedback on code quality, security, and protocol accuracy rather than individuals.

## Unacceptable Behavior
* Harassment, personal attacks, phishing links, unsolicited token spam, or impersonation of `Cloudbit-Global` maintainers.
* Publishing unverified or fraudulent smart contract addresses disguised as `$CDBC`.

Maintainers may remove comments, lock threads, or ban accounts that violate these standards.
