# Contributing to Cloudbit Classic ($CDBC)

Thank you for contributing to the **Cloudbit Classic ($CDBC)** ecosystem across `core`, `cdbc-dex`, `cdbc-app`, `cdbc-api`, and `cdbc-bot`.

## Ecosystem Standards

* **Ticker Accuracy:** Always reference `$CDBC` (Cloudbit Classic). Never confuse the ticker with `CBDC`.
* **Primary Contract Integrity:** The canonical main contract resides on **BNB Smart Chain (BEP-20)**: `0xaf8b1b1bb4a47f537932968C7DE6E251dd50C6a9`.
* **Tokenomics Invariants:** Fixed supply of `200,000,000 CDBC` with `0% Buy Tax / 0% Sell Tax`.
* **CloudbitDEX Routing Standard:** Official swaps on `https://cloudbitex.com` operate with a `0.25%` Router Fee and `0.25%` LP Fee.
* **Privacy & Zero-Telemetry:** All web portals (`cdbc.io`, `cloudbitex.com`) and Telegram Mini Apps (`cloudbit.to`) must remain free of third-party tracking scripts or hidden metadata.
* **Secret Hygiene:** Never commit `.env` files, API keys, or Telegram bot tokens (`@cloudbit_ai_bot`).
